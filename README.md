🏥 MedicareLK – Healthcare Mobile Application

Android Mobile Application | Java | Android Studio | SQL

📌 Project Overview

MedicareLK is an Android-based healthcare mobile application developed to make healthcare services more accessible and convenient for users.

The application provides a user-friendly platform where users can explore doctors, search for healthcare services, manage appointments and access their personal profiles.

This project was developed as part of my Mobile Application Development assignment at ICBT Campus, Sri Lanka.

🎯 Project Objectives

* Develop a user-friendly healthcare mobile application.
* Make doctor searching and appointment booking easier.
* Provide secure user registration and login.
* Allow users to manage their personal profiles.
* Improve access to healthcare-related information.

⚙️ Installation Guide

1. Clone this repository.

git clone https://github.com/ragavan-janoyan/medicarelk-app.git

2. Open Android Studio.
3. Select Open and choose the downloaded MedicareLK project folder.
4. Allow Gradle synchronization to complete.
5. Configure the required database connection.
6. Run the application using an Android emulator or physical Android device.
